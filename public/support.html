Need help with a NIM gas relay?

If you paid the quoted NIM fee and the Polygon supply has not completed, do not send another payment. Check the relay status in Current first.

For support, open a GitHub issue and include the quote ID, Nimiq transaction hash, and Polygon transaction hash if one exists. These transaction details are public on their respective blockchains.

Never include your seed phrase, private key, wallet password, or recovery file. Support will never need them.
