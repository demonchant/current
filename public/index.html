Before you begin

Earn can grow.
It can also change.

Aave supply rates move with the market. No return is promised. Supplying USDT carries protocol, liquidity, stablecoin, and network risks.

Current uses Polygon mainnet. You need USDT to supply and POL for transaction fees. Check the amount, destination, network, and fee before signing.

Honest status Live wallet and transaction behavior must be checked in Nimiq Pay before use. The app shows when market data or wallet access is unavailable.
